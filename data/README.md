# Каталог данных

Содержимое этого каталога **не коммитится в Git** (см. `.gitignore`) — здесь
хранятся образцы и датасеты, включая потенциально вредоносные файлы.

## Ожидаемая структура

```
data/
└── samples/
    ├── malware/          # label = 1
    │   ├── malware_sample_0000.exe
    │   └── ...
    └── benign/           # label = 0
        ├── benign_sample_0000.exe
        └── ...
```

Обучение:

```bash
python main.py train --dataset data/samples
```

## Учебный датасет

Чтобы не хранить реальный malware в репозитории, датасет генерируется
синтетическими, но **валидными** PE-файлами:

```bash
python tools/generate_samples.py --out data/samples --per-class 60
```

Различия профилей:

| Характеристика | `benign` | `malicious` |
|---|---|---|
| Энтропия `.text` | низкая (~0–4) | высокая (~8, случайные байты) |
| Секции | `.text .rdata .data .rsrc` | + `UPX1` (упаковщик), `.tls` |
| Импорты | KERNEL32/USER32/GDI32/msvcrt | + инъекции, реестр, сеть, крипто |
| TLS-callbacks | нет | 2 шт. |
| Оверлей | нет | 512 байт случайных данных |
| `VirtualSize` vs `SizeOfRawData` | совпадают | сильный разрыв (признак упаковки) |

> ⚠️ Сгенерированные файлы **не являются вредоносными**: в `.text` лежат байты-
> заполнители, полезной нагрузки нет. Это «манекены» для проверки конвейера.

## Реальные датасеты

| Источник | Описание |
|---|---|
| [EMBER 2018](https://github.com/elastic/ember) | 1.1M образцов с готовыми признаками |
| [MalwareBazaar](https://bazaar.abuse.ch/) | Реальные образцы (изолированная ВМ!) |
| [VirusTotal](https://www.virustotal.com/) | Вердикты по SHA-256 |

**Правила работы с реальным malware:**

1. Только изолированная ВМ без доступа к сети и к общей файловой системе.
2. Хранить в зашифрованном архиве (традиционно пароль `infected`).
3. Никогда не коммитить — `.gitignore` уже блокирует `data/`, `*.exe`,
   `*.dll`, `*.bin`, `quarantine/`.
4. Обмен внутри команды — по SHA-256, а не пересылкой файлов.
