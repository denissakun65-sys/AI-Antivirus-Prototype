# 🛡️ AI-Antivirus — прототип Next-Gen AV / EDR

Учебный прототип антивируса нового поколения: **статический анализ PE-файлов**
(`pefile`) + **ML-классификация** (Random Forest / LightGBM) + **автоматический
карантин** с шифрованием и контролем целостности.

```
     _    ___   ___         _          _
    / \  |_ _| / _ \  _ __ | |_  _   _(_)__  ___
   / _ \  | | | | | || '_ \| __|| | | | | \/ / / __|
  / ___ \ | | | |_| || | | | |_ | |_| | |   <  \__ \
 /_/   \_\___| \___/ |_| \_|\__| \__,_|_|_|\_\ |___/
```

> ⚠️ **Дисклеймер.** Проект создан **исключительно в образовательных и
> исследовательских целях**. Это *не* замена промышленному антивирусу или EDR:
> здесь нет драйвера ядра, поведенческого анализа, песочницы, проверки
> цифровых подписей и телеметрии. Не используйте его как единственное средство
> защиты и не запускайте реальные вредоносные образцы вне изолированной
> лаборатории.

## ✨ Возможности

| Компонент | Что делает |
|---|---|
| **`aiav.features`** | Разбирает PE и извлекает **46 статических признаков**: геометрия, энтропия секций, таблица импортов (с разбивкой по категориям «тревожных» API), флаги заголовков, TLS-callbacks, оверлей, ресурсы, аномалии. |
| **`aiav.model`** | Класс `MalwareClassifier` — единая обёртка над RandomForest и LightGBM. Обучение, метрики (accuracy / precision / recall / F1 / ROC-AUC / CV), сохранение модели с метаданными и **проверкой схемы признаков при загрузке**. |
| **`aiav.scanner`** | Конвейер «признаки → предсказание → действие». Пакетное предсказание, режимы `quarantine` / `report`, `--dry-run`, JSON + CSV отчёты, коды возврата в стиле антивирусов. |
| **`aiav.quarantine`** | Изоляция с **AES-256-GCM**, карточки в JSON, проверка **SHA-256** при восстановлении, защита от перезаписи, `list` / `restore` / `purge`. |
| **`aiav.cache`** | SQLite-кэш вердиктов, привязанный к **версии модели** (переобучили — кэш автоматически недействителен), + кэш облачной репутации с TTL. Повторное сканирование — в разы быстрее. |
| **`aiav.trustlist`** | Whitelist против ложных срабатываний: доверенные **хеши** файлов и **каталоги** (по умолчанию `C:\Windows`, `Program Files` и т.п.). Команда `trust`. |
| **`aiav.threat_intel`** | Облачная репутация **по SHA-256** (файлы никуда не загружаются): MalwareBazaar бесплатно + VirusTotal по ключу. Консенсус мировых движков уточняет «серую зону» модели. |
| **`aiav.monitor`** | Фоновая защита каталогов на watchdog: новый/изменённый PE проверяется на лету и при необходимости изолируется. Команда `monitor`. |
| **`aiav.overnight`** | Автономное обучение из интернета: EMBER (~1 млн размеченных реальных PE) + легальные open-source бинарники, эпохи без предела, работает до Ctrl+C. Команда `autolearn`. |
| **`tools/generate_samples.py`** | Генератор **валидных синтетических PE** (benign/malicious профили) — чтобы тестировать конвейер, не храня реальный malware в репозитории. |

.\.venv\Scripts\Activate.ps1        # в начале строки появится (.venv)

## 🖥️ CLI-справочник

### `scan` — проверка файлов и каталогов

```bash
python main.py scan <путь> [<путь> ...] [опции]
```

| Опция | Описание |
|---|---|
| `--action {quarantine,report}` | Действие при обнаружении угрозы (по умолчанию `quarantine`) |
| `--dry-run` | Ничего не перемещать — только отчёт. **Рекомендуется для первого запуска** |
| `--model PATH` | Путь к модели (по умолчанию `models/malware_classifier.joblib`) |
| `--quarantine-dir PATH` | Каталог карантина (по умолчанию `quarantine/`) |
| `--malicious-threshold F` | Порог карантина (по умолчанию `0.80`) |
| `--suspicious-threshold F` | Порог «подозрительно» (по умолчанию `0.50`) |
| `--max-file-size MB` | Пропускать файлы крупнее лимита (по умолчанию `256` МБ — как у больших инсталляторов) |
| `--online` | Проверять «серую зону» по облачной репутации SHA-256 (MalwareBazaar, + VirusTotal при `AIAV_VT_KEY`) |
| `--learn` | Копить пары «признаки → консенсус мировых движков» в `data/distill/dataset.csv` для переобучения (подразумевает `--online`) |
| `--no-cache` | Не использовать кэш вердиктов (перепроверить всё заново) |
| `--no-encrypt` | Хранить объекты карантина без шифрования |
| `--full-report` | Включить в JSON-отчёт весь вектор признаков |
| `--no-report` | Не сохранять отчёты |
| `-v / -q` | Подробный вывод / только предупреждения |

**Коды возврата:** `0` — угроз нет, `1` — найдены угрозы, `2` — ошибка
(нет модели, нет прав и т.п.), `130` — прервано пользователем.

### `train` — обучение модели

```bash
python main.py train --dataset data/samples --backend random_forest
python main.py train --csv my_dataset.csv --backend lightgbm --threshold 0.85
```

| Опция | Описание |
|---|---|
| `--dataset DIR` | Каталог с подкаталогами `malware/` и `benign/` |
| `--csv FILE` | Готовый CSV-датасет (EMBER/Kaggle) с колонкой `label` |
| `--backend {random_forest,lightgbm}` | Алгоритм классификации |
| `--output PATH` | Куда сохранить модель |
| `--threshold F` | Порог вердикта MALICIOUS |
| `--test-size F` | Доля отложенной выборки (по умолчанию `0.25`) |
| `--limit N` | Максимум образцов на класс (для быстрых прогонов) |

### `features` — дамп признаков одного файла

```bash
python main.py features suspicious.exe
```

### `quarantine` — управление изолированными объектами

```bash
python main.py quarantine list                     # список объектов
python main.py quarantine restore <ID>             # восстановить по исходному пути
python main.py quarantine restore <ID> --target ./analysis.exe
python main.py quarantine purge <ID>               # удалить безвозвратно
python main.py quarantine purge --all
```

### `model-info` — сведения о модели

```bash
python main.py model-info
```

### `trust` — whitelist против ложных срабатываний

```bash
python main.py trust add <файл>          # доверять SHA-256 этого файла
python main.py trust add-path <каталог>  # доверять всему каталогу (рекурсивно)
python main.py trust remove <sha256>     # снять доверие
python main.py trust list                # показать текущий список
```

Доверенные объекты **не сканируются** моделью — это первый фильтр против
ложных срабатываний на вашем легитимном софте. Список хранится в
`models/trustlist.json`; каталоги вроде `C:\Windows` и `Program Files`
добавлены в доверенные по умолчанию.

### `monitor` — фоновая защита каталогов

```bash
python main.py monitor <каталог> [<каталог> ...] [--online] [--action report]
```

Следит за каталогами (watchdog) и проверяет **каждый новый или изменённый PE**
на лету — с дебаунсом, чтобы не хватать недокачанный файл. Угроза изолируется
тем же карантином AES-256-GCM. Требуется `pip install watchdog`.

> ⚠️ Это userspace-мониторинг (аналог «watched folders»), а не драйвер уровня
> ядра: он видит файловые события, но не перехватывает исполнение процессов.
> Для автозапуска используйте Планировщик задач (Windows) или systemd (Linux).

### `autolearn` — непрерывное обучение из интернета

```bash
python main.py autolearn                     # до Ctrl+C, эпохи без предела
python main.py autolearn --until 07:00       # остановка к 7 утра
python main.py autolearn --backend lightgbm  # быстрее на больших данных
python main.py autolearn --epochs 3          # ровно 3 эпохи
```

| Опция | Описание |
|---|---|
| (без опций) | Работает **бесконечно**: собирает данные, переобучается, снова и снова — пока не нажмёте Ctrl+C |
| `--hours N` / `--until ЧЧ:ММ` | Ограничить сессию временем |
| `--epochs N` | Предел эпох (`0` = неограниченно, по умолчанию) |
| `--backend {random_forest,lightgbm}` | `lightgbm` заметно быстрее на больших объёмах |
| `--retrain-every N` | Переобучаться каждые N строк (по умолчанию 10000) |
| `--max-rows N` | Лимит строк данных (`0` = без лимита, по умолчанию) |
| `--no-ember` | Не скачивать EMBER (~2 ГБ), только benign-бинарники |
| `--ember-url URL_ИЛИ_ПУТЬ` | Зеркало EMBER или путь к скачанному вручную архиву (спасает при HTTP 403) |
| `--no-status-window` | Не открывать отдельное окно статуса (Windows) |

На Windows `autolearn` **сам открывает отдельное окно PowerShell** с доской:

### Если EMBER отдаёт HTTP 403 (региональная блокировка)

CDN `elastic.co` блокирует часть регионов (403/451). Это не ошибка кода.
Варианты:

1. Скачайте архив вручную там, где он открывается (браузер, другая сеть,
   VPN): `https://ember.elastic.co/ember_dataset_2018_2.tar.bz2` (~2 ГБ)
   и положите файл в `data\nightly\ember_dataset.tar.bz2` — `autolearn`
   подхватит его без скачивания;
2. или укажите зеркало/локальный путь: `--ember-url <URL или путь>`
   (либо `AIAV_EMBER_URL`);
3. или работайте без него: `--no-ember` — benign-бинарники, метки
   `scan --learn` и переобучение накопленного продолжат работать.

После 5 ошибок подряд `autolearn` сам отключает EMBER до конца запуска
и продолжает без него (с бэкоффом — бесконечного шквала ошибок больше нет).

Прогресс переживает перезапуск: оборванная закачка EMBER **докачивается**
по HTTP Range, обработанные строки не перечитываются, состояние лежит в
`data/nightly/state.json`.

## ⚙️ Как это работает

```
┌──────────────┐     ┌─────────────────┐     ┌──────────────────┐     ┌────────────┐
│  Каталог     │ --> │  Отбор PE-      │ --> │  Извлечение      │ --> │  ML-модель │
│  (рекурсивно)│     │  кандидатов     │     │  46 признаков    │     │  (RF/LGBM) │
└──────────────┘     │  MZ + расширение│     │  (pefile)        │     └─────┬──────┘
                     └─────────────────┘     └──────────────────┘           │
                                                                            v
                     ┌───────────────────────────────────────────────────────────┐
                     │  P(malware) >= 0.80  ->  MALICIOUS   ->  КАРАНТИН (AES)   │
                     │  P(malware) >= 0.50  ->  SUSPICIOUS  ->  только отчёт     │
                     │  иначе               ->  CLEAN                            │
                     └───────────────────────────────────────────────────────────┘
                                                        │
                                                        v
                                        reports/scan-<timestamp>.{json,csv}
```

**Ключевые инженерные решения**

- **Пакетное предсказание.** Признаки извлекаются пофайлово (это IO-bound),
  а модель вызывается **один раз** для всего набора — скан каталога ускоряется
  в разы.
- **Один битый файл ≠ упавший скан.** Любая ошибка разбора превращается в
  `PEFeatureError` и фиксируется в отчёте со статусом `ERROR`; обход продолжается.
- **Схема признаков — контракт.** Модель хранит `FEATURE_NAMES` в метаданных и
  сверяет его при загрузке. Изменили набор признаков — получите явную ошибку
  «переобучите модель», а не молча деградировавшее качество.
- **Кандидаты отбираются и по сигнатуре, и по расширению.** `payload.bin` с
  заголовком `MZ` попадёт в разбор, а `broken.exe` без PE-заголовка — тоже,
  но уже как ошибка, а не молчаливый пропуск.

## 🔐 Карантин

1. **Файл не исполняется.** Объект переименовывается в `<id>.quarantined`
   (Windows не запустит такой файл как PE) и лишается прав на запись.
2. **Шифрование.** По умолчанию **AES-256-GCM** (`cryptography`). Ключ создаётся
   один раз в `quarantine/.quarantine.key` с правами `0600`. Без
   `cryptography` включается XOR-обфускация — с явным предупреждением в лог,
   что это **не** криптостойкая защита.
3. **Карточка объекта** `<id>.json`: исходный путь, SHA-256, размер, вердикт,
   вероятность, модель, причина, время.
4. **Контроль целостности.** При восстановлении SHA-256 сверяется: подменили
   объект в карантине — восстановление прерывается.
5. **Никакой молчаливой перезаписи.** `restore` откажется затирать существующий
   файл без `--force`.
6. **Права каталога** — `0700` (только владелец). На Windows дополнительно
   рекомендуется ограничить ACL:
   ```powershell
   icacls "quarantine" /inheritance:r /grant:r "%USERNAME%:(OI)(CI)F"
   ```

## 🌐 Онлайн-репутация и обучение у мировых движков

Ключевой принцип Next-Gen AV — **облачная репутация**: файл не обязательно
распознавать локально, если мировой консенсус уже знает его вердикт.

```
Локальная модель даёт «серую зону» (SUSPICIOUS)?
        │
        ▼
SHA-256 файла ──► MalwareBazaar (бесплатно, без ключа)
        │              «известный malware» ──► эскалация до MALICIOUS
        ▼ не найден
VirusTotal (при AIAV_VT_KEY) — вердикты ~70 движков
        ├─ 3+ malicious            ──► эскалация до MALICIOUS
        └─ 10+ harmless, 0 malicious ──► снятие подозрений (анти-ложняк)
```

Включается флагом `--online`. Важно:

- **в облако уходит только хеш** — файлы никуда не загружаются;
- «не найден в malware-базе» ≠ «файл чистый» — чистоту утверждает только
  уверенный консенсус движков;
- ответы кэшируются на 7 дней (`models/verdict_cache.db`);
- без сети сканер продолжает работать полностью локально.

### `--learn`: дистилляция знаний мировых движков в вашу модель

Самое интересное: вердикты коммерческих движков можно **превратить в обучающие
данные** для вашей локальной модели — без единого скачанного образца malware:

```powershell
# 1. Сканируем с обучением: каждый уверенный вердикт облака
#    превращается в строку «46 признаков + метка 0/1»
python main.py scan $env:USERPROFILE\Downloads --dry-run --online --learn

# 2. Когда строк накопилось достаточно — переобучаемся на них
python main.py train --csv data\distill\dataset.csv
```

Так локальная модель постепенно «впитывает» опыт ~70 мировых движков:
они размечают ваши реальные файлы, а она учится на этой разметке офлайн.
После переобучения кэш вердиктов автоматически инвалидируется (ключ кэша
включает версию модели).

> 💡 Собранные метки не нужно переносить вручную: команда `autolearn`
> (ниже) на каждой эпохе сама подтягивает новые строки из этого CSV.

### Какие аспекты лучших антивирусов заимствованы

| Аспект | Откуда идея | Как реализовано здесь |
|---|---|---|
| ML по статическим признакам PE | Эвристика NextGen-движков (Kaspersky, Bitdefender, ESET) | 46 признаков → RandomForest/LightGBM |
| Облачная репутация по хешу | KSN, VT Cloud, SmartScreen | MalwareBazaar + VirusTotal, только SHA-256 |
| Мультидвижковый консенсус | VirusTotal / MalwareBazaar | Эскалация/деэскалация «серой зоны» + метки для `--learn` |
| Кэш вердиктов | Все коммерческие AV | SQLite, ключ = хеш + версия модели |
| Whitelist доверенного ПО | Все коммерческие AV | `trust` + доверенные каталоги по умолчанию |
| Фоновый мониторинг папок | Watched-folder сканеры | `monitor` на watchdog (userspace) |
| Дистилляция знаний | EMBER-подход: модель учится на вердиктах движков | `--learn` → CSV → `train --csv` |
| Карантин с шифрованием | Все коммерческие AV | AES-256-GCM, ключ 0600, карточки JSON |

> **Честная оговорка.** Внутренности коммерческих движков закрыты — скопировать
> их алгоритмы невозможно (и незаконно). Учиться можно только на их **вердиктах**:
> это законно, публично и лежит в основе подхода EMBER. Проект **никогда не
> скачивает** ни образцы malware, ни антивирусное ПО — только хеши уходят
> в запрос и вердикты возвращаются обратно.

## 🖥️ Фоновая защита (мониторинг каталогов)

```powershell
pip install watchdog
python main.py monitor $env:USERPROFILE\Downloads $env:USERPROFILE\Desktop --online
```

Конвейер: событие файловой системы → **дебаунс** (ждём, пока размер файла
перестанет расти, чтобы не проверять недокачанный файл) → фильтр «это вообще
PE?» → полный конвейер сканирования (кэш → whitelist → модель → репутация) →
изоляция угрозы в карантин.

Автозапуск в Windows — Планировщик задач:

```powershell
schtasks /Create /TN "AI-AV Monitor" /SC ONLOGON ^
  /TR "python C:\path\to\ai-antivirus\main.py monitor %USERPROFILE%\Downloads --online"
```

Ограничение по замыслу: это userspace-наблюдатель, а не драйвер ядра —
он реагирует на появление файлов, но не перехватывает запуск процессов.

## 🔄 Непрерывное фоновое обучение из интернета (`autolearn`)

Запустите в фоне и забудьте — остановите, когда захотите:

```powershell
python main.py autolearn --backend lightgbm
```

Что происходит внутри, эпоха за эпохой (число эпох **не ограничено**):

```
ЭПОХА 1                                ЭПОХИ 2, 3, 4, …
────────────────────────               ────────────────────────
1. Качает легальные PE-файлы            1. Подтягивает новые метки из
   с официальных сайтов                    scan --learn (консенсус движков)
   (7-Zip, PuTTY, WinMerge, …)          2. Переобучение на новой случайной
   → признаки → метка 0                    перестановке данных (новый seed)
2. Скачивает EMBER (~2 ГБ) —            3. Модель сохраняется, только если
   ИЗВЛЕЧЁННЫЕ признаки ~1 млн             CV-F1 стал ЛУЧШЕ
   реальных PE-файлов с метками
   консенсуса VirusTotal
   → конвертация в наши 46 признаков
3. Переобучение каждые 10 000 строк
```

Гарантии, заложенные в конструкцию:

- **Модель не может стать хуже.** Каждая кандидатура сравнивается по CV-F1
  с текущей моделью; проигравшая — выбрасывается.
- **Malware не скачивается.** EMBER содержит только статистику
  (заголовки, секции, импорты) — самих файлов там нет. Benign-класс —
  подписанные установщики с официальных сайтов.
- **Можно прервать в любой момент.** Ctrl+C (или закрытие окна) — прогресс,
  датасет и лучшая модель сохраняются; `autolearn` продолжит с той же точки.
- **Дневные сканы питают обучение.** Строки, собранные `scan --learn`
  (вердикты ~70 движков VirusTotal), автоматически вливаются в датасет
  на каждой эпохе.

Честная оговорка про «эпохи»: когда все источники прочитаны, новые эпохи не
изобретают новые данные — они повторно переобучают модель на новых
случайных перестановках и свежих консенсус-метках. Это даёт небольшой, но
настоящий прирост устойчивости; основной скачок качества происходит, пока
идёт первичный сбор EMBER.

## 🚧 Ограничения прототипа

Честный список того, чего здесь **нет** — и что делает промышленный NGAV/EDR:

- **Только статика.** Нет поведенческого анализа, эмуляции, песочницы.
- **Нет проверки подписей.** Authenticode фиксируется как признак, но не валидируется.
- **Реалтайм — только userspace.** `monitor` следит за файлами через watchdog,
  но нет драйвера уровня ядра и перехвата создания процессов.
- **Нет обхода упаковки.** Упакованный образец анализируется «как есть».
- **Синтетическая обучающая выборка.** Метрики на `tools/generate_samples.py`
  близки к 1.0 **по построению** — это смоук-тест конвейера, а не оценка качества
  детекта. Для реальных цифр нужен EMBER или собственный размеченный корпус.
- **Нет защиты от adversary ML.** Признаки легко «зашумить», если злоумышленник
  знает набор (`FEATURE_NAMES` открыт в репозитории).
- **Карантин — пользовательского уровня.** Без ACL уровня SYSTEM объект можно
  удалить, имея права владельца.
